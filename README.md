#### Things you can look at

- **[Atrium](https://github.com/ayaanngandhi/atrium)** — one port 80 front door for
  every service on a LAN: a path router with a single JSON config, a live status
  board, and no dependencies. Python standard library only.
- **[Zingy](https://github.com/ayaanngandhi/Zingy-Downloader)** — a downloader for
  1000+ sites. Android app (Kotlin + Compose, yt-dlp running on-device through
  Chaquopy) and a Flask web app.
- **[Trace](https://github.com/ayaanngandhi/trace)** — a client-side inspector for
  AI media provenance: C2PA credentials, Google's SynthID watermark, and file
  metadata, read entirely in the browser. Nothing is uploaded.
- **[api-hunter](https://github.com/ayaanngandhi/api-hunter)** — a CLI that reads a
  page and prints the internal API endpoints its frontend actually calls.
- **[internal-apis-guide](https://ayaanngandhi.github.io/internal-apis-guide/)** —
  the method behind that: authentication, fingerprints, and reusable clients.
- **[personal-website](https://github.com/ayaanngandhi/personal-website)** — the
  source of [ayaanngandhi.in](https://ayaanngandhi.in).
